# 🌙 OutLight RP – بوت الترحيب والتذاكر

بوت جاهز يسوي لك:
- **رسالة ترحيب** احترافية لكل عضو جديد، فيها البانر والافتار وعدد الأعضاء.
- **نظام تذاكر** كامل بزر فتح/إغلاق، وقناة خاصة لكل عضو، مع رتبة دعم ولوق.

---

## 1) التثبيت

```bash
npm install
```

## 2) الإعدادات

افتح ملف `config.js` وعدّل:

| الحقل | وش تحط فيه |
|---|---|
| `TOKEN` | توكن البوت من [Discord Developer Portal](https://discord.com/developers/applications) |
| `WELCOME_CHANNEL_ID` | ايدي قناة الترحيب |
| `TICKET_CATEGORY_ID` | ايدي الكاتيقوري اللي تنفتح فيها التذاكر |
| `SUPPORT_ROLE_ID` | ايدي رتبة فريق الدعم |
| `TICKET_LOG_CHANNEL_ID` | ايدي قناة لوق إغلاق التذاكر |

> **كيف تجيب الـ ID:** فعّل Developer Mode من إعدادات ديسكورد (Advanced) ثم اضغط يمين على القناة/الرتبة → Copy ID.

## 3) الصلاحيات المطلوبة عند دعوة البوت

عند إنشاء رابط الدعوة من Developer Portal، فعّل:
- `bot` + `applications.commands`
- صلاحيات: `Manage Channels`, `Send Messages`, `Embed Links`, `Attach Files`, `Manage Roles` (للتذاكر)

كذلك فعّل **Server Members Intent** من تبويب Bot في الديفلوبر بورتال (مطلوب لرسالة الترحيب).

## 4) التشغيل

```bash
npm start
```

## 5) الاستخدام

- بمجرد تشغيل البوت، رسائل الترحيب تشتغل تلقائي.
- روح لأي قناة تبي تحط فيها لوحة التذاكر واكتب:
  ```
  /ticket-setup
  ```
  (تحتاج صلاحية Manage Server عشان يشتغل معك الأمر)

- الأعضاء يضغطون زر **📩 فتح تذكرة** → تنفتح لهم قناة خاصة.
- فريق الدعم يضغط **🔒 إغلاق التذكرة** لإغلاقها.

## ملاحظات
- الصور (البانر/الافتار) موجودة داخل مجلد `assets/` وتُرسل تلقائياً مع البوت — ما تحتاج ترفعها بمكان ثاني.
- تقدر تغيّر اللون الأساسي `BRAND_COLOR` في `config.js` لو حبيت.
- البوت مبني بـ **discord.js v14** ويشتغل على أي استضافة تدعم Node.js (Railway, VPS, إلخ).
